01 / Коротко

Два разных инструмента для разных задач

Сравнивать их напрямую — не совсем честно

GitHub Pages

  • Бесплатный статический хостинг от GitHub
  • Отдаёт только HTML/CSS/JS — без баз данных и серверного кода
  • Автоматический деплой при пуше в репозиторий
  • Свой CDN (Fastly) и HTTPS из коробки

VPS

  • Виртуальный сервер с полным root-доступом
  • Можно запускать любой backend: Node.js, PHP, базы данных
  • Вы сами настраиваете и обновляете сервер
  • Платный — от пары сотен рублей в месяц

Главное отличие: GitHub Pages отдаёт только готовые файлы, VPS — полноценный компьютер, на котором можно запустить что угодно, включая backend и базу данных.

03 / Выбор

Что выбрать в вашем случае

Три типичных сценария

  • Лендинг, визитка, портфолио, блог — GitHub Pages с головой хватает, и это бесплатно
  • Сайт с личным кабинетом, оплатой или формами — нужен backend, а значит VPS (или serverless-функции как промежуточный вариант)
  • Интернет-магазин, SaaS-сервис — почти всегда VPS: нужна база данных, авторизация, обработка платежей

Если не уверены — начните с GitHub Pages. Перейти на VPS позже, когда появится реальная потребность в backend, всегда можно — домен и фронтенд переносятся без проблем.

04 / Гибрид

Гибридный вариант — то, что часто выбираем мы

Статика + serverless-функции без своего сервера

Необязательно выбирать одно из двух. Многие сайты держат фронтенд на GitHub Pages (бесплатно, быстро, свой CDN), а для конкретных задач — оплата, отправка формы, бот — используют serverless-функции (например, на Vercel), которые запускаются только когда нужны и не требуют администрирования сервера.

VPS в этой схеме подключают, только когда нужно что-то постоянно работающее в фоне — например, своя база данных или сложная бизнес-логика, которую неудобно дробить на отдельные функции.

05 / FAQ

Частые вопросы

Короткие ответы на главное

Можно ли подключить свой домен к GitHub Pages?

Да, через файл CNAME в репозитории и настройку DNS-записей у регистратора домена — HTTPS подключается автоматически в течение суток.

Выдержит ли GitHub Pages высокую посещаемость?

Да, файлы отдаются через CDN Fastly — это та же инфраструктура, что держит миллионы сайтов. Для статики лимитов посещаемости на практике почти не встретить.

Сложно ли администрировать VPS самому?

Требует базовых знаний Linux и терминала — обновления системы, настройка файрвола, SSL-сертификатов. Если это не ваш профиль, проще заказать разработку сайта под ключ.
