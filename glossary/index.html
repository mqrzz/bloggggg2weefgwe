A–D
API
Application Programming Interface — способ, которым одна программа обращается к другой. Например, ваш сайт может через API получать курс валют или отправлять сообщение в Telegram-бота.
CDN
Content Delivery Network — сеть серверов по всему миру, которая раздаёт файлы сайта из точки, ближайшей к пользователю. Подробнее — в статье о скорости загрузки.
CMS
Content Management System — система управления контентом (например, WordPress). Позволяет редактировать сайт через админку без правки кода — ценой более тяжёлого и медленного сайта.
DNS
Domain Name System — «телефонная книга» интернета: превращает имя домена (antviz.ru) в IP-адрес сервера, на который нужно отправить запрос.
Домен
Человекочитаемое имя сайта (antviz.ru) вместо цифрового IP-адреса. Полностью разобрали в гайде по доменам.
H–J
Honeypot
Приём защиты формы от спам-ботов: скрытое CSS-полем поле, которое видят и заполняют только автоматические боты — а значит, заполненное поле выдаёт спам.
HTTPS
HTTP поверх шифрования TLS. Защищает данные между браузером и сервером от перехвата. Разобрали в статье про HTTPS и сертификаты.
JSON-LD
Формат микроразметки Schema.org — блок кода, который объясняет поисковику, что за контент на странице (статья, товар, организация). Разобрали в статье про SEO.
L–R
Let's Encrypt
Бесплатный центр сертификации, который выпускает SSL-сертификаты на 90 дней с возможностью автопродления. Стандарт для большинства современных сайтов.
Robots.txt
Текстовый файл в корне сайта, который говорит поисковым роботам, какие разделы можно индексировать, а какие — нет.
S
Serverless
Код, который выполняется в облаке только в момент вызова — без постоянно работающего сервера. Пример использования — в статье про формы без бэкенда.
Sitemap.xml
Файл-список всех страниц сайта, который явно передаётся поисковику, чтобы он быстрее находил новый контент.
SSL / TLS
Протоколы шифрования соединения между браузером и сервером. SSL — устаревшее название, сейчас везде используется TLS, но термин «SSL-сертификат» прижился по привычке.
Static site / статический сайт
Сайт из готовых HTML/CSS/JS-файлов без сборки на сервере «на лету» — быстрее и проще в поддержке, чем сайт на CMS.
T
TTFB
Time To First Byte — время от запроса страницы до получения первого байта ответа от сервера. Один из ключевых показателей скорости.
TTL
Time To Live — время жизни записи в кэше или DNS, после которого данные считаются устаревшими и запрашиваются заново.
V–Я
VPS
Virtual Private Server — виртуальный сервер с полным доступом, на котором можно запускать любой backend. Сравнение с GitHub Pages — в статье про хостинг.
Вебвизор
Инструмент Yandex Metrika, который записывает реальные сессии посетителей — видно, где именно человек теряется на сайте.
Критический CSS
Стили только для первого экрана, вставленные напрямую в <head>, чтобы браузер не ждал загрузки всего CSS-файла перед отрисовкой.
Кэш
Временное хранилище данных, которое позволяет не запрашивать одно и то же заново — например, браузер кэширует картинки и шрифты сайта.
Микроразметка
Дополнительная разметка на странице, которая объясняет поисковику структуру и тип контента. Смотрите JSON-LD выше.
